# brand.md

Copy this to `~/.claude/instagram/brand.md` and fill it in. Do not commit the
filled-in copy anywhere: it holds facts about you, and this repo stays free of
them.

Every skill reads this file first. A skill never guesses a field from your
profile, your bio or a few posts. If a field it needs is empty, it asks you.
If a claim is not written here, it does not go into a draft.

Leave a field blank rather than writing something vague. Blank means "ask me".
